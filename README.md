## Features
- Dark design system with bold typography (CSS variables)
- Scroll animation system built on IntersectionObserver (`.reveal` + `data-delay`)
- Sticky navigation with logo, four smooth-scroll links and a blur glass effect on scroll
- Animated accretion-disk hero

## Run your own
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main / root).
